Phần I

🌍 Tạo Thế Giới Mô Phỏng

Khái niệm về World (thế giới mô phỏng)

World là một tệp tin lưu toàn bộ thông tin mô phỏng: vị trí và hình dáng các vật thể, cách chúng tương tác, màu sắc bầu trời, trọng lực, ma sát, khối lượng… Nó xác định trạng thái ban đầu của phiên mô phỏng.

Nodes (Nút)

Mỗi đối tượng trong thế giới là một Node — robot, hộp, ánh sáng, sàn…

Scene Tree

Các Node sắp xếp theo cấu trúc cây phân cấp cha–con.

File .wbt

Lưu dưới dạng văn bản VRML97 — có thể mở bằng VS Code hoặc Notepad++.

Lưu ý quan trọng: Không lưu project trong thư mục mặc định của Webots. Khi mở Sample World, luôn dùng Save World As… để tránh làm hỏng file mẫu.
Bài Thực Hành

Tạo và kiểm tra World đầu tiên

  1. 1 Mở Webots. Chọn File → New → New Project Directory.
  2. 2 Nhấn Next, tạo thư mục mới ở ổ D (hoặc ổ E).
  3. 3 Đặt tên project. Tick hết vào các ô, đặc biệt ô "Add a rectangle arena". Nhấn Finish.
  4. 4 Trong Scene Tree, nhấp đúp RectangleArena. Đặt floorTileSize = 0.25 0.25 và wallHeight = 0.05.
Phần II

📦 Thực Hành Thả Vật Thể

Bước 1

Thêm vật thể WoodenBox

Nhấp đúp RectangleArena → Add (+) → PROTO nodes / objects / factory / containers / WoodenBox(Solid).

Bước 2

Chỉnh kích thước & vị trí

Đặt size = 0.1 0.1 0.1 và translation = 0 0 0.05.

Bước 3

Di chuyển & Sao chép

Shift + chuột trái để kéo. Ctrl+C / V để nhân bản.

Bước 4

Xoay & Lưu

Dùng mũi tên màu xanh để xoay hoặc Shift + chuột phải. Nhấn Save để lưu.

Phần III

🤖 Thêm Robot E-puck

E-puck là robot bánh xe vi sai nhỏ gọn sở hữu 10 đèn LED, 8 cảm biến khoảng cách và một camera — lý tưởng cho thực hành mô phỏng.

Quy tắc thời gian: Luôn Pause → Reset → Modify → Save. Đảm bảo đồng hồ hiển thị 0:00:00:000 trước khi chỉnh sửa.

Thêm robot vào scene

Chọn node WoodenBox cuối cùng → Add (+) → PROTO nodes / robots / gctronic / e-puck / E-puck (Robot). Điều chỉnh vị trí và nhấn Run — robot sẽ tự tránh chướng ngại vật!

Bạn có thể thêm bất kỳ robot nào trong Nodes → robots nhé!

Tác dụng lực vật lý

OSPhím tắt
Windows / LinuxAlt + chuột trái + kéo
macOSOption ⌥ + chuột trái + kéo
Tăng độ chính xác mô phỏng: Pause → Revert → mở node WorldInfo → đặt basicTimeStep = 16 (ms) → Save.
Phần IV

💻 Tạo Bộ Điều Khiển (Controller)

Controller là chương trình xác định hành vi của robot. C / C++ / Java cần biên dịch (compile); Python / MATLAB là ngôn ngữ thông dịch.

  • Một controller có thể dùng cho nhiều robot cùng lúc.
  • Mỗi controller chạy trong một tiến trình độc lập với file .wbt.

Tạo và liên kết Controller

  1. 1. Vào File / New / New Robot Controller… → chọn C → đặt tên epuck_go_forward.
  2. 2. Chỉnh sửa mã nguồn trực tiếp trong Text Editor của Webots.
  3. 3. Mở Node E-puck → trường controller → Select… → chọn epuck_go_forward.

Robot tiến thẳng — epuck_go_forward.c

epuck_go_forward.c 
#include <webots/robot.h>
#include <webots/motor.h>

#define TIME_STEP 64

int main(int argc, char **argv) {
  wb_robot_init();

  WbDeviceTag left_motor  = wb_robot_get_device("left wheel motor");
  WbDeviceTag right_motor = wb_robot_get_device("right wheel motor");

  wb_motor_set_position(left_motor,  10.0);
  wb_motor_set_position(right_motor, 10.0);

  while (wb_robot_step(TIME_STEP) != -1) { }

  wb_robot_cleanup();
  return 0;
}
Thực thi: Lưu mã nguồn → Build → Reset → chạy mô phỏng. File nhị phân sẽ có tên epuck_go_forward.exe trong thư mục controller.
Phần V

🚀 Điều Khiển Tốc Độ Bánh Xe

Để điều khiển robot bằng vận tốc thay vì vị trí góc quay, đặt mục tiêu vị trí là INFINITY rồi gọi wb_motor_set_velocity().

epuck_speed_control.c 
#include <webots/robot.h>
#include <webots/motor.h>

#define TIME_STEP 64
#define MAX_SPEED 6.28

int main(int argc, char **argv) {
  wb_robot_init();

  WbDeviceTag left_motor  = wb_robot_get_device("left wheel motor");
  WbDeviceTag right_motor = wb_robot_get_device("right wheel motor");

  // Bật chế độ speed control (vị trí → vô cực)
  wb_motor_set_position(left_motor,  INFINITY);
  wb_motor_set_position(right_motor, INFINITY);

  wb_motor_set_velocity(left_motor,  0.1 * MAX_SPEED);
  wb_motor_set_velocity(right_motor, 0.1 * MAX_SPEED);

  while (wb_robot_step(TIME_STEP) != -1) { }

  wb_robot_cleanup();
  return 0;
}

Tóm tắt điều khiển motor

Chế độHàm APIKhi dùng
Position set_position(angle) Quay đúng góc nhất định
Velocity set_position(∞)
set_velocity(v)		 Di chuyển liên tục
