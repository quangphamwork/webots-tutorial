Controller Là Gì?

Khái Niệm

Trong Webots, Controller là chương trình được gắn với robot để điều khiển robot trong mô phỏng. Nó nhận thông tin từ các cảm biến, xử lý thông tin và đưa ra lệnh để robot hành động.

Câu Hỏi Đặt Ra

Đứng trước vật cản, robot phải làm gì? Controller chính là bộ não giúp robot trả lời câu hỏi này — đọc cảm biến, phân tích và ra quyết định.

API — Bộ Công Cụ Giao Tiếp Với Webots

API có thể hiểu đơn giản như một bộ công cụ gồm những hàm được Webots cung cấp sẵn, giúp chương trình Controller giao tiếp và điều khiển các đối tượng trong mô phỏng.

Ví dụ dễ hiểu: Mình đang dùng ngôn ngữ C để viết chương trình, nhưng Webots không thể tự hiểu mọi câu lệnh C liên quan đến robot. Vì vậy Webots cung cấp một bộ API — giống như một bộ câu lệnh có sẵn — để nói cho Webots biết: hãy điều khiển motor này chạy với tốc độ này.
Ví dụ cụ thể: Khi sử dụng webots/distance_sensor.h, các bạn có thể sử dụng những hàm wb_distance_sensor_* để lấy giá trị từ cảm biến khoảng cách.

Cấu Trúc Vòng Lặp Phản Hồi (Feedback Loop)

Mỗi bộ điều khiển robot tiêu chuẩn đều hoạt động theo một vòng lặp khép kín bao gồm các bước theo trình tự nghiêm ngặt sau:

Giải Thích Từng Bước

feedback_loop.c
wb_robot_init();
int time_step = wb_robot_get_basic_time_step();
// ... khởi tạo thiết bị ...

while (wb_robot_step(time_step) != -1) {
  // Đọc cảm biến
  ps_values[i] = wb_distance_sensor_get_value(ps[i]);

  // Xử lý logic
  if (left_obstacle) { /* rẽ phải */ }

  // Ghi motor
  wb_motor_set_velocity(left_motor, speed);
}
wb_robot_cleanup();
Nhấn Start để bắt đầu mô phỏng
Sơ đồ bên phải sẽ tự động chạy qua từng bước trong vòng lặp phản hồi của Robot Controller.
Vòng lặp: 0 / Bước: -
Ví Dụ Thực Tế

Vòng lặp phản hồi có khắp nơi trong cuộc sống:

  • Lái xe: Quan sát (cảm biến) → Phân tích (não) → Bẻ lái (motor) → Lặp lại
  • Điều hòa: Đo nhiệt độ → So sánh mức cài → Bật/tắt quạt → Lặp lại
  • Robot hút bụi: Dò tường → Quyết định hướng → Quay bánh → Lặp lại
  • Game loop: Input → Update → Render → Lặp lại (60 FPS)

Bài Thực Hành Số 2 — Khai Báo Thư Viện và Cấu Hình Thời Gian Step

Giới Thiệu Thư Viện

  • robot.h: Chứa hàm wb_robot_init(), wb_robot_step() và wb_robot_cleanup().
  • distance_sensor.h: Hỗ trợ kích hoạt và đọc dữ liệu quang từ các cảm biến ps0 – ps7.
  • motor.h: Hỗ trợ điều khiển vị trí, gia tốc và vận tốc quay cho bánh xe.
  • TIME_STEP: Robot sẽ cập nhật trạng thái vật lý mỗi chu kỳ (mili-giây).

Bài Thực Hành Số 3 — Thiết Lập Hàm Main và Vòng Lặp Phản Hồi

Cơ Chế Đồng Bộ Hóa

  • wb_robot_init(): Bắt buộc chạy đầu tiên để giao tiếp giữa trình mô phỏng và code.

Bài Thực Hành Số 4 — Khởi Tạo Cảm Biến và Động Cơ Bánh Xe

Điểm Mấu Chốt Cần Nhớ

  • WbDeviceTag: Là kiểu dữ liệu định danh phần cứng trong Webots (C). Các ngôn ngữ OOP dùng đối tượng trực tiếp.
  • wb_distance_sensor_enable(): Bắt buộc phải kích hoạt cảm biến trước khi đọc giá trị.
  • Chế độ Vận tốc (Velocity Mode): Đặt vị trí là INFINITY giúp động cơ quay liên tục thay vì dừng ở một góc xác định.

Thêm đoạn mã cấu hình tag thiết bị và kích hoạt chu kỳ quét cho 8 cảm biến hồng ngoại cùng hệ thống motor ngay trước vòng lặp while:

Bài Thực Hành Số 5 — Hoàn Thiện Thuật Toán Tránh Vật Cản

Nguyên Lý Điều Hướng

  • Đi thẳng: Cả 2 bánh quay cùng chiều với tốc độ cơ sở 0.5 * MAX_SPEED (~3.14 rad/s).
  • Gặp cản bên trái: Đảo chiều bánh phải quay lùi (-0.5 * MAX_SPEED), bánh trái quay tiến → Robot xoay sang phải.
  • Gặp cản bên phải: Đảo chiều bánh trái quay lùi, bánh phải quay tiến → Robot xoay sang trái.

Thêm các đoạn mã xử lý đọc dữ liệu và kiểm soát vận tốc bánh xe vào bên trong vòng lặp while:

C — Thuật toán tránh vật cản
// read sensors outputs
double ps_values[8];
for (i = 0; i < 8 ; i++)
  ps_values[i] = wb_distance_sensor_get_value(ps[i]);

// detect obstacles
bool right_obstacle =
  ps_values[0] > 80.0 ||
  ps_values[1] > 80.0 ||
  ps_values[2] > 80.0;
bool left_obstacle =
  ps_values[5] > 80.0 ||
  ps_values[6] > 80.0 ||
  ps_values[7] > 80.0;

// initialize motor speeds at 50% of MAX_SPEED.
double left_speed  = 0.5 * MAX_SPEED;
double right_speed = 0.5 * MAX_SPEED;

// modify speeds according to obstacles
if (left_obstacle) {
  // turn right
  left_speed  = 0.5 * MAX_SPEED;
  right_speed = -0.5 * MAX_SPEED;
}
else if (right_obstacle) {
  // turn left
  left_speed  = -0.5 * MAX_SPEED;
  right_speed = 0.5 * MAX_SPEED;
}

// write actuators inputs
wb_motor_set_velocity(left_motor, left_speed);
wb_motor_set_velocity(right_motor, right_speed);

rightMotor->setVelocity(rightSpeed);

Lưu Ý Quan Trọng Khi Biên Dịch & Chạy

Bước 1 — Build: Sau khi viết xong code, bắt buộc phải nhấn nút Build (biểu tượng hộp bánh răng) trên thanh công cụ Text Editor để biên dịch mã nguồn. (Với Python/MATLAB, chỉ cần Save.)
Bước 2 — Kiểm tra lỗi: Nếu xuất hiện lỗi chữ màu đỏ ở cửa sổ Console, hãy kiểm tra kỹ ký tự hoặc cú pháp dòng báo lỗi để chỉnh sửa.
Bước 3 — Reload: Sau khi tiến trình biên dịch báo thành công (chữ xanh), bắt buộc phải nhấn nút Reload thế giới mô phỏng trên thanh công cụ Webots thì robot mới nạp thuật toán mới. Nếu quên bước này, robot sẽ đứng yên hoặc chạy theo dữ liệu cũ!
